7Fold

Initial Hurdles

For this project we assembled a very talented group of individuals.

Two designers, two coders and a project manager.

We had to develop a fully working game that is able to be completed in 4 weeks.

We all settled on the genre horror and we all had amazing ideas to process. Eventually what was chosen was a platformer with horror elements.

Now for the actual process of what really went on.

Development Journey

The first 2 weeks I had to spend a lot of time playing around with SpriteKit.

I also developed a joystick within it which I was very proud of since the logic didn't allow to escape the outer ring and directly mapped to the characters movement, direction and speed.

Then after it reality hit since I have to actually develop a game now.

I implemented cross device scaling (iPhone & iPads), animations which there were a lot of (talented designers❤️), physics (for sure my weakest), and a lot of other things.

Along with after school nights developing with my other coder and improvising ideas on the fly like menu music and in game soundtracks/bites.

Results

After all that work the game was essentially done.

I am very proud of what my group accomplished within those 4 weeks since to make a actual polished version would take an indie team like a couple months.

Empathy Experience

The Context

In Apple Academy, this was a very special project we got so far.

The constraints were no social media app along with us having to stick with a big idea/theme along with designing an app for a user.

My groups big idea was empathy along with our user being Jazmine Middlebrooks.

Jazmine has a history of teaching along with being in multiple groups to spread the message of mistreatment in groups of minorities.

My group didn't want our app to be too boring, politically focused or too broad.

We wanted to make an educational and fun app which is game oriented targeted for people who want to learn about the struggles of people of color in the professional/educational spaces.

This is where Empathy Experience comes in.

Separations of Concerns

In our group now that we have an idea of what we want to accomplish.

Before we even began our jobs, we had a consensus vote if we should prioritze learning or execution. My group chose execution so I went along with that.

We split responsibilities, my role was the main developer along with an acquitance with a solid role in design. This was mainly if the designers need extra help along with feedback since I am the one writing most of the code architecture.

We had to make sure the app is accessible for a huge audience while remaining fun. Now let's walk over how we did it along with how I executed this while working with two designers.

Performance under Pressure

Since this was an ambitious project considering the amount of time we had for development which was like 7 days worth of class time. Along with making last minute design decisions this was phenomenal execution.

I had to take this project home outside of class to make sure the job is finished.

The architecture I went with was MVVM since this was a game so essentially normal SwiftUI navigation is off the table (users can't go back and cheat). The ViewModel made it very easy for me to store logic and switch views programatically.

My designers were so busy with performing the final touches on the UI that we forgot about the app icon itself. So the night before, I remembered and took it upon myself.

Icon Composer was surprisingly pretty simple to someone like me who doesn't daily drive designer tools. I learned a lot about and more importantly how to apply a icon composer file as app icon in Xcode through a godsend Reddit post.

Resolution

After all that, we accomplished actually in fact over exceeded our original expectations.

Our target user was very pleased with the results and impressed considering the circumstances.

MADCAP

The Story

This was a solo project that everyone was assigned to do.

We had to create a iOS app prototype for a chosen coffee shop.

If you are a Detroit native you might've heard of MADCAP.

It is a minimalist coffee shop that has been around for awhile, a lot of black and white colors along with vibrant painting and plants in the shop to stand out.

It was my job to create a very simple CRUD app to take in user input, calculate cost and display the order out in the end.

Execution

I learned a lot during this process like generics to create a reusable Picker across types. Along with UI design especially in Sketch.

Also leaned very hard on Apple's native components since that is minimalist and familiar by design.

Even added a tip amount along with error handling if a user doesn't input a name for the order along with handling if a user doesn't specify any notes for the order.

This was a very good learning experience and I would highly recommend it to anyone looking to learn SwiftUI or iOS development.

The app is open source on GitHub
